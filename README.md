### 🎮 Arcadia

**Arcadia: Echoes of Power V2** est un modpack NeoForge 1.21.1 de plus de 490 mods et 3 000 quêtes, porté par une équipe bénévole et accompagné de son réseau de serveurs.

J'y tiens le rôle de développeur principal : les mods serveur de l'équipe, et l'infrastructure sur laquelle tourne le tout — Linux, Docker et Proxmox sur serveurs dédiés.

| Mod | Rôle | Téléchargements |
|---|---|---:|
| [Arcadia Admin Pannel](https://github.com/Team-Arcadia/Arcadia-Admin-Pannel) | Panneau d'administration in-game : modération, équipes, chunks | 57.9K |
| [ArcadiaGuard](https://github.com/Team-Arcadia/ArcadiaGuard) | Protection de régions, flags, permissions | 56.8K |
| [arcadia-patch-create](https://github.com/Team-Arcadia/arcadia-patch-create) | Correctifs pour l'écosystème Create | 54.9K |
| [ArcadiaTweaks](https://github.com/Team-Arcadia/ArcadiaTweaks) | Optimisations serveur et correctifs via mixins | 24.4K |
| [Arcadia Games](https://github.com/Team-Arcadia/Arcadia-Games) | 32 mini-jeux compétitifs, scores et classements, FR/EN | 2.2K |
| [TesseraUI](https://github.com/Blushister/TesseraUI) | Framework d'interfaces in-game | 111 |
| [Arcadia-Dungeon](https://github.com/Team-Arcadia/Arcadia-Dungeon) | Donjons configurables : boss adaptatifs, vagues, récompenses | 84 |

**Correctifs amont** — faire tenir un pack de cette taille demande aussi de réparer des mods tiers en 1.21.1 : crashs au lancement, incompatibilités, conditions de course en dispatch parallèle. Voir [Ecologics](https://github.com/Team-Arcadia/Ecologics), [ImmersiveMelodies](https://github.com/Team-Arcadia/ImmersiveMelodies), [AnimalGarden-Owl](https://github.com/Team-Arcadia/AnimalGarden-Owl), [DeeperAndDarker](https://github.com/Team-Arcadia/DeeperAndDarker).
